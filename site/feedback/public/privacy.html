Feedback privacy and security

Send only material you have permission to share. Avoid passwords, API keys, personal records, and confidential documents.

What we receive

The website accepts your message, optional contact email, and selected files. Standard Nextshot exports can contain clean screenshots, screen text, window titles, and notes. The app sends a smaller support package with annotated screenshots, notes, and basic app version information.

How we process it

Cloudflare stores submissions privately. Isolated scanners check files and text for malware, sensitive information, and suspicious instructions. Cloudflare-hosted AI also screens content and prepares private issue drafts. No submission authorizes code changes or publication.

Screening can miss harmful or private material. A successful check means no issue was detected. It does not guarantee safety. Suspected issues and incomplete checks keep the submission held.

Access and delivery

Only the owner can open the review page. Original uploads are not downloadable there. Screened text goes to the owner's Gmail inbox. Screened files remain behind protected links. Replying from that inbox uses the owner's personal Gmail address.

Retention

Held material expires 30 days after receipt. Screened material expires 90 days after receipt. This includes stored files and issue drafts. Gmail keeps delivered text under its own retention settings.

We use a keyed identifier derived from the submitting IP address for abuse limits. We do not store raw IP addresses in the feedback database. Operational logs exclude message bodies and sensitive findings.

Anonymous submissions are welcome. Without a contact address, we cannot reply. Contact addresses supplied through the form or app are not verified.
