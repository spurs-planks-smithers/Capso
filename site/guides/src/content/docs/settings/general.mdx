Use **General** to start Nextshot at login, check its version, or open the Nextshot feedback form.

<GuideImage src="/guides/media/settings-general.png" alt="The General tab shows Launch at Login, Version, Report a Bug, and Request a Feature." caption="General keeps startup, version, and feedback controls together." />

<Step number={1} title="Choose startup behavior">

Open **Settings**, then **General**. Choose whether Nextshot starts when you sign in to your Mac. On first use, select **Done** to save your choice.

If macOS requires approval, choose **Open Login Items** and allow Nextshot. Turning startup off keeps it off after updates. Disabling Nextshot in macOS Login Items also keeps it off.

This control does not start a round or make a capture.

</Step>

<Step number={2} title="Check the installed version">

Find the version in **About**. The Nshot menu also shows the running version and build.

**About** also has **Remind me about new versions**, which is on by default. About 7 days after you first run a build, Nextshot shows one reminder and a **Get the latest version…** row in the Nshot menu. The row opens nextshot.dev, which tells you whether a newer build is out. Nextshot stays offline and sends nothing. Turn the switch off to hide the reminder and the row. Nextshot 0.6.0 and later has this switch.

</Step>

| Control | Default | When to use it |
| --- | --- | --- |
| Launch at Login | Your saved choice | Keep Nextshot available after login. |
| Version | Installed build | Identify the running copy when you need help. |
| Remind me about new versions | On | Get one reminder to check nextshot.dev for a newer build. |
| Report a Bug | n/a | Open the Nextshot feedback form for a problem. |
| Request a Feature | n/a | Open the same form for an idea. |

## Send feedback

Choose **Report** beside **Report a Bug** or **Request** beside **Request a Feature**. Both open the Nextshot feedback form at [feedback.nextshot.dev](https://feedback.nextshot.dev).

Opening the form sends no report. Review your message and any files before you submit them.

Updates use a new installer. [Install an update](/guides/install/#install-an-update) when a newer release is available.
