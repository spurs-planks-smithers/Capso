The printable reference is a one-page Letter PDF. These are the default keys. Your settings may use different ones.

## Start a capture

| Action | Default shortcut |
| --- | --- |
| Start or add a capture | <Shortcut keys={['Option', 'Shift', 'F']} /> |

Press the capture key, then drag to select an area. The first saved capture starts a round.

## Mark the capture

| Action | Key |
| --- | --- |
| Add the next numbered dot | Click, with the dot tool selected |
| Select the dot tool | C or N |
| Select the arrow tool | A |
| Select the box tool | R |
| Select the text tool | T |
| Save and open notes | Command+S |
| Undo or redo a mark | Left or Right arrow |

Left and Right control mark history when you are not typing text. They beep when no history is available.

Escape with no marks copies the screenshot image and closes the editor. With marks, Escape follows the editor’s step-back behavior.

## Answer the note questions

| Action | Key |
| --- | --- |
| Save the answer and continue | Return |
| Skip the current step | Escape |
| Move to an earlier or later step | Up or Down arrow |
| Move back from the start of an answer | Left arrow |
| Move forward from the end of an answer | Right arrow |

## During a round

| Action | Default shortcut |
| --- | --- |
| Copy Last Capture Prompt | <Shortcut keys={['Option', 'Shift', 'C']} /> |
| Copy Prompt and End Round | <Shortcut keys={['Option', 'Shift', 'R']} /> |
| Open Round Folder | <Shortcut keys={['Option', 'Shift', 'O']} /> |
| End Round and copy its prompt | <Shortcut keys={['Option', 'Shift', 'E']} /> |

The four round keys work only while a round is active. Finish an open capture before using R or E.

## Change a shortcut

Open **Settings**, then **Shortcuts**. The **Nextshot** section comes first. It holds the five actions for starting and managing rounds.

<GuideImage src="/guides/media/settings-shortcuts.png" alt="The Shortcuts tab shows the five Nextshot actions first, with Advanced below." caption="Change a round key beside its action. Open Advanced for the centered-selection key." />

Click the key field beside the action. Press your new key combination. Press Escape while recording to cancel. Press Delete while recording to remove the shortcut.

For the start key alone, choose **Change Start Round Shortcut** in the Nshot menu. Nextshot refuses a key another action already uses.

<details>
<summary>Advanced: centered square selection</summary>

Open **Advanced** in **Shortcuts**. **Center 1:1 from click** sets the extra key for a square that grows around your first click.

The default extra key is C. Hold Shift during area selection, then hold the extra key shown in this row. Shift stays fixed. Click the extra key field to change that key. Press Escape to cancel.

</details>
