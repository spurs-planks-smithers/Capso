# Embedded preview context trial

The trial starts off. Capture once, then open the popup to see discovered embedded sites. Enable the trial with its checkbox. Use Allow embedded sites to grant only the listed origins and restart area selection. Chrome remembers each site grant. Turning the trial off restores full iframe covers. No grant includes all websites.

Ordinary capture, sampled recording, and Rolling Round use `beginFrameContext(tabId)` before the screenshot. Each path keeps its top-page proof. Each confirms the frame proofs after the screenshot. Each releases observers in `finally`. Pixel masks run before a draft or a recording frame enters storage. The existing nonuniform scale check remains required.

The module returns replacement top-level `elements` and `privateRects`. Bounds use top-page CSS pixels. Element IDs and selectors include the frame index path. Frame URLs use the existing sanitizer. Source file locations remain unavailable.

Each injected frame finds its index path through WindowProxy identity comparisons. The parent reports iframe border and viewport bounds. Chrome supplies document IDs. Confirmation targets those same documents. Mutation, navigation, scroll, geometry, and animation checks reject changed snapshots. A snapshot expires after 1500 milliseconds.

An inaccessible iframe stays fully covered. A sandboxed frame can participate only when its embedding element permits `allow-same-origin` and its effective document origin is not opaque. Content Security Policy and inherited sandbox restrictions can still make that origin opaque. Those frames stay covered, including when `location.origin` names an HTTP origin. About/blob documents, frames inside shadow trees, transformed frames, uncertain clipping, and mismatched viewports stay covered. Unknown grandchildren retain their own covers. Open and closed shadow form fields inside an otherwise supported document receive private masks. Recordings do not alter the source DOM or pause animations.

The extension has no idle frame injection. Origin discovery runs only during explicit capture or armed sampling. New iframe origins require another explicit grant. No debugger or browsing-history permission is used.

Controlled headless fixtures verify cross-origin and nested bounds, exact child matches, ordinary/recorded private pixels, closed shadow inputs, denied-site fallback, readable sandbox support, opaque sandbox fallback, navigation rejection, mutation rejection, and transformed fallback. A nine-case sandbox check also covers Content Security Policy, inherited restrictions, and changed sandbox flags before navigation. Production Claude Design and Artifacts account tests remain separate release checks.

October 29 pilot acceptance: the supplied private Artifact works in regular Chrome after its explicit child-site grant. A numbered mark identifies the embedded heading. Drew saves the capture and confirms prompt copy. This proves that Artifact and the controlled cases. It does not establish support for every Claude Design page, animated preview, or future frame configuration.
