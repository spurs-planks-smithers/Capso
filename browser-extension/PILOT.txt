NEXTSHOT PILOT

Private Chrome-only test for Windows and Mac.
No Nextshot app, account, Python, or other software is required.
The software license is included in LICENSE.txt.
Use a current version of Google Chrome.

INSTALL ONCE

1. Extract the entire ZIP. On Windows, right-click it and choose Extract All.
2. Keep the extracted Nextshot-Pilot folder in a stable location.
3. In Chrome's address bar, type chrome://extensions and press Enter.
4. Turn on Developer mode. Click Load unpacked.
5. Select the extension folder inside Nextshot-Pilot.
6. Verify the name is Nextshot Pilot. Pin it from Chrome's puzzle menu.

This is an unpacked private pilot. Chrome may show developer notices.
If your organization blocks Developer mode, do not bypass that restriction.
Report it to the person who invited you.

MAKE FEEDBACK

1. Open a safe website. Click Nextshot Pilot, then Capture an area.
2. Approve access to that site if Chrome asks. Drag around the area to capture.
3. Click the image to add a numbered dot. Add a note beside it.
4. Click Save & copy instructions. Your feedback is saved and its instructions are copied.
5. Click Download ZIP. Chrome downloads screenshots, notes, and page details.

Paste the copied instructions into a text editor or coding agent.
Click an existing numbered dot to read or change its note.
Page details are included automatically when available. They need no review.
If several parts could match a dot, you can choose one or continue saving.

When using a coding agent, attach that exported ZIP.
It contains the images and element details.
The copied text names files inside that ZIP.

The suggested capture key is Option+Shift+B on Mac or Alt+Shift+B on Windows.
The popup and editor show the key Chrome actually assigns.
If another extension uses that key, choose Set capture shortcut once.
Chrome opens its shortcut settings. Assign an available key to Nextshot Pilot.
After setup, use that key in Chrome to capture without opening the popup.
Command+S saves on Mac. Ctrl+S saves on Windows.
Saved rounds are available from the extension's popup.
End current round starts a fresh group on your next capture.

DATA AND LIMITS

Captures and notes stay in this Chrome profile. Nothing uploads automatically.
No AI, native integration, recording, or Rolling Round is included in this pilot.
The toolbar, popup, and editor use Nextshot's approved logo.
Form fields and unreadable embedded previews receive covers.
Field details contain structure and position, without field contents or labels.
A mark beside an element can suggest a nearby target. Check that suggestion.
Images and notes can still contain private data. Review them before sharing.
Only capture content you are comfortable sharing with your coding agent.
An embedded preview may need its own site grant. Allow preview details appears
in the popup after a capture discovers a preview that needs permission.
Return to the source website tab before opening that popup.
Changing pages during capture can require another capture.
Chrome internal pages, the Web Store, PDFs, and local files are outside this test.
Source file locations are unavailable unless the page provides reliable details.

UPDATE OR REMOVE

Keep the same extension folder. Replace its files with the next pilot build.
Open chrome://extensions and click Reload on Nextshot Pilot.
Reloading preserves saved rounds. Removing the extension clears its browser data.
Export rounds before removal. Exported ZIP files remain on disk.
