# Nextshot Pilot: friend test (Windows and Mac)

Owner: Drew. Issue: #182. Private test. Send this page and the Pilot ZIP only to a friend Drew has chosen. Nothing uploads automatically. The ZIP name is on the issue; it holds `TRY-THIS.txt` with the same steps.

You need Google Chrome (current version). You do not need the Nextshot app, an account, or any other software. A test takes about 10 minutes.

## Install once

1. Extract the whole ZIP. On Windows, right-click it and choose Extract All.
2. Keep the `Nextshot-Pilot` folder where it is. Chrome reads it from there.
3. In Chrome, type `chrome://extensions` and press Enter.
4. Turn on Developer mode. Click Load unpacked. Select the `extension` folder inside `Nextshot-Pilot`.
5. Check that the name reads Nextshot Pilot.

If your organization blocks Developer mode, stop. Do not bypass it. Tell the person who invited you.

## The one key

Mac: **Option+Shift+D**. Windows: **Alt+Shift+D**.

If nothing happens, click the puzzle-piece menu, click Nextshot Pilot, then click Capture an area. If Chrome says the key is taken, click Set capture shortcut once and pick a free key.

## Test steps

Use harmless content. Do not capture private pages or passwords.

1. Open https://example.com. Press the key. Approve site access if Chrome asks. Drag around the heading.
2. Click the heading to add dot 1. Type: Change this heading to Pilot test.
3. Press Return. On General note, press Return again. This saves and copies the instructions.
4. Paste into any text editor. You should see a Feedback round header and your note.
5. Back in the feedback tab, press X. Chrome downloads a ZIP. Open it. Check `README.md` and the marked image.
6. Make a second capture with two dots and two notes. Do not save it. Quit Chrome fully, then reopen it.
7. Click the Nextshot Pilot icon. Click Resume unsaved capture. Your dots and notes should be there. Press Command+S (Mac) or Ctrl+S (Windows) to save.
8. Open the popup and confirm the saved rounds are listed.
