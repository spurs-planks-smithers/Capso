# Research note 07: Affinity and proximity as working structure for the agent

Date: 2026-11-01. A research agent (Sonnet) wrote this note for the visual direction study. It is raw evidence, not a decision. The synthesis is `docs/research/2026-11-01-visual-direction-research.md`. Numbers are as the agent read them; the synthesis marks the findings that were checked by hand.

Outcome: the evidence supports two moves, put related items next to each other and give the agent a running record of decisions. No study I found tests cluster-grouped items in a coding agent prompt, so treat the grouped handoff as a hypothesis to test in shadow mode. I opened every source below this session. "Abstract only" marks sources where I read only the abstract. I edited no file.

### 2. Ideas for the handoff

1. **Grouped item index.** Compute clusters from the local signals below, with a conservative threshold. Leave singletons ungrouped, in capture order after the groups. Show it in the refined prompt, like the existing "Order and lanes" section. Keep K.N ids and the on-disk prompt.md unchanged. Put the general item first in each group. Evidence: Chen (order), Huang (distance), Roberts (links).
2. **Shared-cause line per group.** Write it as a search order: "K.2, K.5, K.9 name text size on text elements in one app. Find the one shared source before you edit any of them. Report it." Build the label from the top shared OCR and note words, with no model. Evidence: LASE, CodePlan, GraphRAG. Keep it short, per Gloaguen.
3. **Related edges with named signals.** In manifest.md and feedback.json, list each pair above threshold and the signals that fired: same window title, same app, shared OCR tokens, shared note words, capture gap in seconds, badge distance on one screen. The agent weighs the evidence. Evidence: Zhang (fields plus text), Cooper (screen plus OCR).
4. **Extend the plan table.** The prompts already demand an item, file, planned change table. Add Group and "same as K.N" columns. The agent must fill the shared decision once per group. Evidence: CodePlan, LASE.
5. **Edit ledger.** Ship groups.json: one row per group with decision (blank), target files, and status. The agent updates it as it works. Use JSON. Evidence: Gautam (+43.9%), ACE (collapse). Anthropic says JSON is overwritten less than Markdown but gives no numbers ([Young, Nov 2025](https://anthropic.com/engineering/effective-harnesses-for-long-running-agents)).
6. **Search lines per group.** List shared strings and window titles to grep. Find locations by search first. Let the model edit second. Evidence: Google migrations, where an LLM wrote 74.45% of 595 changes after location discovery ([Ziftci+ FSE 2025, abstract only](https://arxiv.org/abs/2504.09691)).
7. **Shadow mode first.** Follow the Jev pattern: write groups to a review file, let Drew label each pair "same cause" or "different," and score each signal. Then A/B agent consistency with and without groups. Evidence: Zhang found data age flips tool rankings, so test on your own data.

Local signals (no model unless noted): same window title and app, OCR token overlap (BM25), note word overlap, capture gap, badge distance on one screen, embedding cosine (small on-device model).

### 3. Contradictions and open questions

1. **No direct test.** All adjacency evidence comes from logic, math and QA. Premise order used 2024 models. I found no 2026 replication on current frontier models.
2. **Gains may be small.** Clustered against contiguous tree: 0.8 points. RAG beat GraphRAG on NQ. Han et al. report judge position bias that flips outcomes.
3. **Extra context can cost.** Gloaguen found about +20% cost with no significant success gain. Would a theme block behave the same?
4. **Which signal wins.** Lexical plus categorical beat complex methods (Zhang). BERT led in a small abstract-only study (Patil). I found no opened study for badge distance or time gap as predictors of a shared fix.
5. **Chinese-vendor dependence.** ACE tables use DeepSeek-V3.1. The pooled Gloaguen average includes Qwen Code. The distance result includes Qwen2.5 7B.

Not verified: Apple NLEmbedding documentation did not load, so I cite no Apple model. PROMISE 2011 time-window duplicate results appeared only in search summaries, so I cite none.
