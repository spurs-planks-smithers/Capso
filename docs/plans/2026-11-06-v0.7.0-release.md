# Nextshot 0.7.0 release

Approved by Drew on November 6, 2026.

## Outcome

Publish the signed and notarized Nextshot 0.7.0 DMG at nextshot.dev, with matching Guides and release notes. Drew asked for "v0.07.0". SemVer 2.0.0 (section 2) forbids leading zeros, and `scripts/nextshot-version.sh` refuses a non-SemVer `VERSION`, so the version is 0.7.0 and the tag is `nextshot-v0.7.0`.

## Scope

| Change | PR |
| --- | --- |
| Five-word round and capture names, shorter Nshot menu (#263) | #263 |
| Option+Shift+E and R end the round from the note panel (#266) | #267, Guides #268 |
| Copy Selected and Clear Selection in each round submenu (#264) | #270 |
| Hover preview of a capture row (#265) | #270 |
| Guides staging stops on an empty or missing `pagefind.js` | #269 |

Out of scope: PR #262 (`linkedPlan`), Chrome drafts #161 and #173. Zip Selected stays behind `zipHandoff`, which is off in release builds, so the public notes leave it out.

## Sequence

1. Rebase the candidate branch on `main`. Run FeedbackKit, JevKit in Release, and app tests.
2. Build Nextshot Dev from the candidate and run the 7-step live check from `docs/plans/2026-11-02-v0.7.0-submenu-copy-and-hover-preview.md`.
3. Merge #270 and #269.
4. Merge this docs change: release notes, `reuse-rounds.mdx`, and the `CHANGELOG.md` wording.
5. Preflight in a clean worktree on `main`: signing file, live video and poster, `apple-notary` profile, `scripts/release.sh --dry-run minor`.
6. Drew runs `scripts/release.sh minor` in a terminal and answers its one question.
7. Verify the live DMG, `latest.json`, footer version, release notes, Guides search, and `/stats`.

## Accepted limits

- Only Nextshot Dev runs on m5pro. Production installer acceptance runs on another approved Mac.
- Only the built-in display was connected, so the second-display preview check did not run.
- GitHub Actions started no CI run on this repository after 2026-11-02. Drew approved merges on local test results on 2026-11-06.
- Released files never change. A bad build gets 0.7.1.
