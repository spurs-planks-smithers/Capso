## Dev check

Drew checked Nextshot Dev builds 934 to 937 on m5pro. Three rounds of his feedback changed Find Capture before release:

1. A search field at the top of the Nshot menu, with Return opening the window (the Find Capture row stays).
2. Option+Shift+S opens the menu with the cursor in the field, and Command+A, C, X, V, and Z work in both search fields.
3. A large preview after the pointer rests 0.5 seconds on a card.

The first typed key in the menu field arrived about 300 ms late. Posted CGEvent keys reproduced it, and a main-thread sample showed AppKit filling every lazy submenu (`historyListing()`) while it looked for a key equivalent. `menuHasKeyEquivalent` now returns false, and the first key arrives in 1 to 3 ms. Option+Shift+S activates Nextshot, so the caret blinks. A menu opened by a click keeps Nextshot inactive and shows a steady caret.

Final check, all passed: Find Capture (search, checks shared with the menu, Space for Quick Look, round label and Back, hover preview, Esc), Zip Round (`nextshot-round-2026-11-08-1020-2-captures.zip`: one top folder, `README.md` first, JPEG images, no AppleDouble entries, no `/Users/` path in the README), and the linked round prompt pasted as text.

Local tests before the release: FeedbackKit 449, JevKit 370, app 261, `test-release.sh` all checks.

## First release run: stopped before its commit

The first run passed preflight and tests, then stopped in the Bump step. `release.sh` ran a plain `git add` that included `site/guides/src/content/docs/release-notes.mdx`. Upstream's `.gitignore` ignores every `docs/` folder, so git exited 1 and the script stopped. Nothing was committed, tagged, built, pushed, or uploaded. The release worktree was restored to `origin/main`. PR #285 adds `commit_release` (`git add -f` of the named paths only) and a `test-release.sh` fixture with an ignored `docs/` folder. The helper tests in #282 had not run that `git add`.
